## وصف المشروع
نظام إدارة التهديدات السيبرانية مع ميزات الكشف عن التصيد، مسح PII بالعربية، سجل تدقيق مع цепочка SHA-256، وتقرير AI threats، وإشعارات فورية، وإدارة التنبيهات.

## Key Features
- Honeypot Detection
- AI Threat Summary Generation (Arabic)
- Arabic PII Scanner (IDs, IBANs, Phones)
- Forensic Capabilities (Tamper-proof Audit Log)
- PDF Report Generation
- Real-time Alert Management
- Desktop Launcher with Shortcut

## Tech Stack
- Backend: FastAPI (Python)
- Database: SQLite
- Frontend: React + TypeScript + Tailwind CSS
- Network Monitoring: Scapy
- Hashing: SHA-256

## How to Install & Run
### Backend
- Clone repository
- cd cybergarde-backend
- pip install -r requirements.txt
- python main.py

### Frontend
- cd cybergarde-frontend
- npm install
- npm run dev

### Prerequisites
- Windows OS (Administrator rights required)
- Python 3.9+
- Node.js 18+
